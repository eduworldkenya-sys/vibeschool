# VibeSchool PWA Icons

These launcher assets are derived from the approved VibeSchool visual identity supplied by the owner.

Rules:
- launcher icons use the VibeSchool symbol only; do not add tiny wordmarks
- preserve generous safe area for adaptive/maskable launchers
- retain the deep-navy background and multicolor V identity
- keep 192 and 512 variants visually equivalent
- do not restore the legacy black/gold `V + VIBE` treatment

The manifest references these files directly. Any asset rename must update `app/manifest.ts`, `app/layout.tsx`, the offline page, and the PWA contract test together.
