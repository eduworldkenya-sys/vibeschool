# HQ Workforce Complete Team Loop

This convergence task owns eight inseparable acceptance outcomes:

1. Worker profiles expose role, responsibilities, current/recent work, authority, evidence, failures and collaborators.
2. Worker Room shows real sender → receiver handoffs with timestamps and inspectable backing records.
3. Founder can assign real HQ work items to governed workers through owner-only persistence and a visible lifecycle.
4. HQ shows the organization clearly: Laban coordinates and specialists remain independently governed.
5. Human status language is primary: Available, Working, Waiting for review, Blocked, Stopped. Technical states remain available underneath.
6. Primary Workforce navigation is mobile-first and does not require horizontal scrolling; technical surfaces move under a compact More selector.
7. Completion proof distinguishes a completion claim from accepted/verified completion and shows verification/evidence/collaboration state.
8. Identity Registry explicitly flags permanent technical workers that are not mapped to a named identity; temporary/system workers remain visibly classified as such.

## Autonomous convergence loop

Discover exact current main and production-compatible Worker Engine contracts → preserve existing authority/security and fail-closed runtime → implement all eight outcomes as one coherent HQ experience → add owner-only persistence where needed → add deterministic identity/status/proof semantics → certify exact head against current main → reconcile if main moves → merge only when required checks are green → verify merged main contains the complete eight-outcome scope.

## Non-negotiable safety boundaries

This task must not activate Worker runtime, increase autonomy/risk, grant worker authority, weaken RLS, bypass verification, or reinterpret a human-facing name as a security principal. Human names remain presentation identities over canonical technical workers.
