# History Production Readiness Checklist v1

Use this before any Form 4 History unit is labelled publication-ready.

## A. Curriculum integrity — blocking
- [ ] Correct subject/curriculum/form
- [ ] Official topic/content codes preserved
- [ ] Objective text verified against authority artifact
- [ ] Objective ↔ content leaf mapping correct
- [ ] No Grade 10 History & Citizenship cross-binding
- [ ] Scope neither omits required content nor invents curriculum requirements

## B. Historical accuracy — blocking
- [ ] Dates verified
- [ ] names/titles verified
- [ ] places/borders/geography verified
- [ ] treaty/organisation facts verified
- [ ] chronology internally consistent
- [ ] causal claims supported and not overstated
- [ ] disputed interpretations identified where material
- [ ] quotations/statistics have exact provenance or are removed
- [ ] source ledger complete for material factual claims

## C. Teaching quality — blocking
- [ ] prerequisite bridge
- [ ] motivating hook/problem
- [ ] explicit learner outcomes
- [ ] vocabulary explained in context
- [ ] explanations answer what/why/how/so-what
- [ ] causal relationships made explicit
- [ ] chronology understandable
- [ ] examples serve learning rather than decoration
- [ ] misconceptions anticipated and corrected
- [ ] formative checks distributed through lesson
- [ ] expected answers/feedback supplied
- [ ] historical-thinking task included where applicable
- [ ] closure connects back to objective
- [ ] remediation and extension options

## D. Teacher usability — blocking
- [ ] scheme mapping available
- [ ] lesson-plan derivation available
- [ ] teacher deep notes
- [ ] board/summary notes
- [ ] activities + expected learner responses
- [ ] resources/visual briefs
- [ ] formative assessment
- [ ] homework + marking guidance
- [ ] test/exam items + blueprint metadata
- [ ] marking scheme
- [ ] reflection/next-lesson prompt

## E. Student usability — blocking
- [ ] mobile-friendly Learn sequence
- [ ] study notes
- [ ] quick revision notes
- [ ] timeline/chronology support
- [ ] key people/places
- [ ] glossary
- [ ] embedded checks
- [ ] practice progression from recall to explanation
- [ ] KCSE command-word coaching
- [ ] model/strong response where useful
- [ ] weak-answer diagnosis
- [ ] mastery/revision pathway

## F. Assessment validity — blocking
- [ ] each item maps to objective/content leaf
- [ ] question tests taught content
- [ ] command word matches expected response
- [ ] marks match required depth
- [ ] marking guidance contains defensible points
- [ ] alternative valid responses allowed where appropriate
- [ ] no keyword-only marking for explanation
- [ ] difficulty/cognitive demand tagged
- [ ] cumulative assessment has coverage blueprint
- [ ] generated questions labelled VibeSchool practice

## G. Accessibility/editorial — blocking
- [ ] ordinary Form 4 learner can follow language
- [ ] technical terms defined
- [ ] no unexplained jumps in chronology
- [ ] headings/chunks suitable for phone reading
- [ ] no giant note-wall where interaction/chunking is needed
- [ ] visuals have instructional purpose and text alternative brief
- [ ] tone is teacherly, not robotic or patronising
- [ ] repetition is purposeful
- [ ] no fake stories/quotes

## H. Derivation/version integrity — blocking
- [ ] canonical artifact version recorded
- [ ] Teacher OS derivatives retain source version
- [ ] Student OS serves only certified content
- [ ] teacher overrides do not mutate canonical content
- [ ] assessment bank version recorded
- [ ] historical teaching evidence remains bound to used version

## I. Independent gates
Required verdicts:
- Curriculum Guardian: PASS
- Fact Checker: PASS
- Pedagogy Reviewer: PASS
- KCSE Examiner: PASS
- Learner Editor: PASS
- Independent Critic: PASS

Any blocking failure returns artifact to REPAIR. Author cannot self-certify.

## J. Final states
`SKELETON → DRAFT → QA → NEEDS_REPAIR → RE-QA → CERTIFIED → PUBLISHED`

`CERTIFIED` means educational/product contract passed. `PUBLISHED` is a separate release action and must never be implied by certification alone.

## World Wars completeness gate
Topic 24.0.0 cannot be called complete until all nine leaves are certified:
- WWI Causes
- WWI Course
- WWI Results
- League Formation
- League Organisation
- League Performance
- WWII Causes
- WWII Course
- WWII Results

Plus cumulative World Wars assessment/revision must have valid coverage across the six official objectives.
