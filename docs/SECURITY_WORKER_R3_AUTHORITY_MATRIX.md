# Security R3 Authority Matrix

| Capability | Certified competence | Runtime authority after certification |
|---|---:|---:|
| Read security metadata | Yes | Read-only qualification path only |
| Record evidence-backed finding | Yes | Evidence only |
| Recommend release block | Yes | Advisory only; cannot block/release production itself |
| Request approval/escalation | Yes | Request only |
| Alter RLS or policies | No | No |
| Grant/revoke authority | No | No |
| Disable/delete users | No | No |
| Rotate credentials/secrets | No | No |
| Release/publish | No | No |
| Change Global Stop/runtime policy | No | No |
| Destructive security repair | No | No |

Certification is evidence of competence, not an executable security authority grant. Consequential security mutations remain behind explicit governed/human authorization.
