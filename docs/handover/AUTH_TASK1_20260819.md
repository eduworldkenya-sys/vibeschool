## P0 root causes and repairs

1. Access authority and onboarding could disagree for admins. `get_my_auth_journey_state()` now owns the canonical profile/role/domain/onboarding/destination state; legacy resolver RPCs are projections of it.
2. Teacher onboarding and its callback fallback referenced nonexistent `teacher_classes.is_active`. The canonical resolver uses real production schema and membership-constrained class assignment.
3. The callback contained a second application-side authority fallback. It is removed: a PostgREST/schema failure now fails recoverably rather than selecting a weaker state path.
4. Production negative-case injection exposed `min(uuid)` in learner identity resolution. `current_student_id()` and canonical learner resolution now count, reject ambiguity, and select the sole UUID deterministically.
5. Protected callback `next` paths with query/hash suffixes could bypass prefix classification because role checks used the full string. Role classification now normalizes to pathname before matching.
6. `/auth/error` recovery now has functional Try Again, Change account/logout, VibeSchool Home, pending state, local failure state, safe public copy, and >=48px primary tap targets.

## Canonical state machine

The database determines: authenticated identity → profile → account status → effective role authority → canonical domain identity/readiness → onboarding state → destination. Admin profile text alone is insufficient; admin/owner membership is required. Students require exactly one active canonical learner for ready state. Teachers require canonical teacher membership and a class assignment in the same school. Parents require a link to an active canonical learner. Ambiguous identity fails closed.

## Security properties

- Canonical identity resolver is `SECURITY DEFINER`, binds `auth.uid()` internally, fixes `search_path`, revokes PUBLIC/anon, and grants only authenticated/service_role.
- Legacy role/access/onboarding RPCs project the same resolver rather than competing with it.
- Anonymous execution of these private identity RPCs is denied.
- Callback deep links are role-checked after stripping query/hash for classification.
- No callback table fallback can bypass canonical authority.
