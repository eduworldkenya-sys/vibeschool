# HQ Navigation & UX Acceptance Contract

This change is complete only when the canonical HQ shell satisfies all of the following:

- Desktop exposes every founder destination through one grouped registry and supports collapsing the sidebar without losing route access.
- Mobile and touch devices never render the persistent desktop sidebar over page content.
- Mobile provides a real full navigation drawer containing the same registry as desktop.
- Mobile keeps only high-frequency shortcuts in the bottom bar; Menu opens the full registry.
- HQ destination search is reachable from desktop and mobile without navigating to another page first.
- Tablet/touch layouts use the mobile-safe shell when pointer/viewport signals are ambiguous.
- Founder Control Room cards remain readable and single-column where necessary on narrow screens.
- Existing owner authority and Supabase access checks remain unchanged.
- The labels required by the HQ control-room contract remain present, including Home, Decisions, Operations, Product, Schools, Users, Content, Curriculum Authority, Content Factory, Revenue, System, Workforce and Commissioning.
