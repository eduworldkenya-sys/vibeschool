# Canonical Class Workbook

Entry: ClassHub → Open Class Workbook (`/teacher/classhub/[id]/workbook`).

The workbook is a projection of the active school, assigned classes/subjects and current `student_classes` enrolments, using `students.id` as row identity. A missing enrolled identity fails the load rather than silently shrinking the roster. Pagination avoids PostgREST's default response limit. Every connected query retains existing RLS and school/class/teacher context.

| Sheet / capability  | Authority and behavior                                                                                                                                                                                                                                                                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Class list          | Current enrolment, admission number, claimed learner account, all group memberships, learner drill-down                                                                                                                                                                                                                                                               |
| Attendance          | Daily register only; date entry and selected-learner bulk present/absent through `upsert_attendance_batch`, followed by read-back. Lesson attendance remains in its existing register. Unmarked learners are never assumed present.                                                                                                                                   |
| Assessments         | Released scores, latest released attempt per assessment; existing gradebook handles moderation and publication.                                                                                                                                                                                                                                                       |
| Exams               | Existing `exams` and `exam_results`; marks 0–100 or ABS; blank is missing, ABS is excluded from scores. Save requires assigned subject, unlocked same-school exam and current enrolled learner. Existing RLS rechecks every write.                                                                                                                                    |
| Comparisons         | Same subject and exam type for learner movement; same exam/subject for another assigned same-school class; averages use recorded non-absent results and disclose count/missingness. Tied ranks use competition ranking over the whole current class. Position is hidden until selected in Columns.                                                                    |
| Homework            | Teacher's canonical homework and submissions; group-targeted work applies only to current group members; drafts do not count as submitted; due dates use Nairobi calendar dates.                                                                                                                                                                                      |
| Progress / revision | Outcome-linked competency evidence, latest observation per outcome, with curriculum outcome text. No invented mastery, demographic inference or predictive risk labels.                                                                                                                                                                                               |

Existing memberships are preserved.                                                                                                                                                                                        |
| Parent follow-up    | Authorized parent-link relationships and teacher-message dates, plus private reason, last contact, agreed outcome and follow-up date. Recording a note never sends a message.                                                                                                                                                                                         |
| Interventions       | Existing intervention queue and canonical intervention workspace, with private support-plan and review-date columns.                                                                                                                                                                                                                                                  |
| Custom sheets       | Participation, reading, project/practical, resources, consent/items and blank templates; text, number, date, checkbox and constrained numeric sum/average/difference. Formula inputs must all exist; missing is never zero.                                                                                                                                           |
| Grid tools          | Frozen learner column, search, numeric sorting, bounded natural-language quick questions, date/term/subject/group filters, column visibility/order, selected-learner fill, saved views, rename, custom column removal with undo, undo/redo.                                                                                                                           |
| Imports             | CSV/XLS/XLSX and TSV paste: one learner ID or unique admission number plus selected column value(s); heading-row toggle and downloadable import template. Validate all rows, preview named learners, apply to draft then explicitly save. Never match by row position/name. Duplicate/ambiguous/unknown learner IDs fail the entire preview. 2 MB / 1,000-row bounds. |
| Exports / recovery  | Visible/filtered rows and columns to Excel/CSV/PDF/print. Spreadsheet formula injection is neutralized. Custom values reflect the draft; academic exports reflect saved authority. JSON draft backup/restore validates schema and current roster. Unsaved drafts block refresh and warn on browser exit.                                                              |

`teacher_class_workbooks` stores only the teacher's private definitions, custom cells and view configurations. It does not hold copied attendance/marks/homework/mastery. RLS requires the owner, active teacher profile, same-school teacher membership and canonical class assignment. Trigger validation applies even to direct table writes. Notes already saved for transferred learners may remain unchanged but cannot accept new edits, and transferred learners never appear in the current workbook. Saves compare expected revision and fail on stale writes instead of last-write-wins.

Recovery: additive migration; roll back the UI commit without removing the private table or deleting teacher notes. Runtime, publishing, schedulers and payments are untouched. Contribution/consent trackers are not a fees ledger or a payment capability.

Verification: `scripts/test-class-workbook.mjs` exercises projections, imports, missing/absent/zero semantics, unknown commands, formula constraints and export safety. `scripts/test-class-workbook-db.mjs` runs the actual SQL migration and existing group RLS against isolated PostgreSQL fixtures, testing allow/deny, cross-school writes, ownership, stale revisions, malformed cells, transfer retention, membership revocation and group retry atomicity. `scripts/test-class-workbook-ui.mjs` renders the workbook DOM and certifies draft editing, conflict recovery, learner search, Excel/CSV/PDF export parity and browser print invocation. These isolated fixtures do not claim a signed-in production journey. The full application type/build and existing governance/migration CI remain required on the exact PR head.
