# Live Production Studio

Approved product direction: one lesson plan, one preparation workspace, one execution engine and connected learning evidence.

## Workflow
Curriculum and scheme/occurrence -> canonical lesson plan -> private preparation -> private rehearsal -> live teaching -> actual assessment evidence -> reflection and remediation. Instant lessons remain supported. Plan stages are guidance, never proof of delivery or learner achievement. Teacher-only plan prose must never automatically become learner-facing content. Use the canonical lesson plan delivery projection and existing resource/assessment authorization.

## Teacher experience
Prepare, Rehearse, Teach live share the same project. Add Content -> Arrange -> Preview -> Teach. Simple labels Now showing, Up next, Show next, Edit current. Advanced production controls are opt-in. Desktop scene navigator, central canvas, contextual inspector; mobile monitor tabs. No duplicate classroom, slide renderer or audio engine.

## Requirements
- Mixed ordered segments: text, images, video, animation, interactive teaching tools, simulation, whiteboard, textbook, document, question, poll, audio.
- New segment, combined composition and progressive reveal; manual progression default, optional timed/activity cues with teacher override.
- Preview private; authoritative Program renders current room content; same-scene live edits preserve identity. Existing access, consent, resource checks and assessment permissions remain.
- Link plan stages, objectives and actual delivery evidence through durable identities and authorized records. Do not mark plan stages completed merely by showing a slide.
- Reusable resources, templates, notes, spotlight, pointer, transitions, animation controls, audio mixer, rehearsal, opt-in recording/replay and export. Never expose private notes or learner voice by default.
- Verify reconnect, late join, access denial, mobile, accessibility, reduced motion, network performance, save recovery and teacher/learner runtime before release.

## Current increment
Existing draft slides remain the sequence storage. Plan stages may be copied as private notes into blank draft segments; learner content must be authored separately. This is not durable stage-to-evidence linking or a complete mixed-media composition system. Existing 30-slide limit and publication path remain. No schema change in this increment. Reconcile concurrent slide work (#2140, #2144), pass required CI and verify production before claiming availability.

## Scope constraint
No AI features in this release. Reuse existing tools and avoid speculative architecture. Prioritize reliable manual lesson preparation, sequence and live execution. Recording and advanced effects remain separate future increments.
