## Verification contract

No completion or merge claim until every approved reference has a mapped route and result. Verify real interaction controls, loading/empty/error states, missing-data truth, keyboard access, phone/desktop layouts, no clipping, save authority preservation and exact-head checks. Compare rendered screens with references; theme matching alone fails acceptance.

Performance must be measured separately from loading placeholders. Avoid duplicate requests and heavy eager bundles. Private cached data remains authenticated-user and authorised-school scoped. Layout changes must not change grades, attendance, curriculum coverage or release authority.

Rollback: revert the scoped application change; no schema or production record migration is planned.

## Candidate verification limits

Local build and interaction checks are development evidence, not signed-in production verification. Desktop/phone rendering, exact-head CI, independent assurance and deployment lineage remain required before completion. No production learner records were modified for testing.

The shared matrix regression was tested with a negative control: changing the shared subject/outcome identity back to learner-specific keys fails the one-column assertion. Restoring canonical keys passes. Long lesson content remains fully available behind disclosure.
