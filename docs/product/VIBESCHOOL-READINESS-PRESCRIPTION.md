# VibeSchool Readiness Prescription

## Purpose

The public readiness assessment should not end at a score. A school leader needs a useful next decision: where connection is strongest, where fragmentation is greatest, which first workflow to pilot, what evidence should be earned and how to run a bounded first month.

The prescription is deliberately **browser-local**. Individual answers are not transmitted, stored or attached to a school identity. Existing public telemetry records only start/completion band events.

## Prescription contract

Every completed assessment produces:

1. readiness score and band;
2. strongest area to protect during change;
3. biggest fragmentation to investigate first;
4. one recommended first workflow;
5. an explicit evidence-to-earn statement;
6. a 30-day bounded pilot plan;
7. a print/save action for the school leader.

## Deterministic recommendation map

The lowest-scoring dimension determines the first workflow. Ties resolve in stable question order so the same answers always produce the same prescription.

- Curriculum visibility → curriculum → scheme → lesson visibility.
- Teaching continuity → teach-this-lesson continuity.
- Evidence → lesson evidence → next action.
- Family context → family progress clarity.
- Leadership → school learning brief.
- Role boundaries → identity and role-authority map.
- Future direction → learner → Pathways evidence journey.
- System connection → Plan → Teach → Evidence → Assess → Next Action.

This is a planning recommendation, not an external audit diagnosis.

## 30-day pilot

### Days 1–5 — Baseline

Map the current workflow, who has authority, current time/duplication and the exact success measure before changing the process.

### Days 6–10 — Prepare

Configure only the first workflow, train the smallest useful group and test the devices/connectivity conditions the pilot depends on.

### Days 11–24 — Run

Use the workflow under ordinary school conditions. Capture implementation, reliability, workload and educational-usefulness evidence.

### Days 25–30 — Decide

Compare against baseline, expose limitations and choose one of three outcomes: **expand, adjust, stop**.

Expansion is earned by evidence rather than assumed.

## Relationship to the Evidence Engine

The Readiness Prescription chooses the first problem and pilot. The Evidence Engine defines how the pilot becomes defensible proof. A future school implementation should preserve this chain:

**Readiness → prescription → pilot contract → baseline → implementation → verification → decision → permissioned public evidence.**

## Research basis

The structure is consistent with implementation guidance that recommends selecting a tight area of focus, preparing deliberately, monitoring implementation with pragmatic measures and deciding how to sustain/scale based on evidence. Reference reviewed: Education Endowment Foundation, A School's Guide to Implementation, https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/implementation
