# VibeSchool School Buyer / ROI System

## Objective

A school leader may understand VibeSchool and still be unable to justify purchasing or piloting it. The business-case system translates a school-defined operational problem into a measurable pilot without inventing savings, ROI, pricing or outcomes.

## Economic model

The calculator uses only buyer-entered assumptions:

- teachers in scope;
- measured weeks;
- avoidable minutes per teacher per week by workload lane;
- buyer-defined target reduction;
- optional loaded staff cost per hour.

It returns:

- addressable workload in the selected measurement window;
- capacity hours if the buyer's target is achieved;
- optional illustrative capacity value using the buyer's own hourly cost;
- the workload lane with the largest entered friction;
- a recommended first pilot and primary baseline measure.

It does **not** claim that the addressable workload will be removed, that capacity will become cash savings, or that VibeSchool has achieved the target before a pilot measures it.

## Workload lanes

1. Planning and duplicate lesson administration.
2. Assessment, marking and recording duplication.
3. Leadership reporting and information chasing.
4. Family progress communication.

These lanes map directly to connected VibeSchool workflows rather than generic software categories.

## Buyer psychology

The goal is not to maximize the headline number. The goal is to reduce decision risk:

- expose assumptions;
- start with the largest credible friction;
- define a baseline before implementation;
- make the stop/revise option explicit;
- separate capacity value from guaranteed cash savings;
- force commercial scope to follow the actual workflow and support need.

A trustworthy business case should make it easier for a school to say **no** when the evidence is insufficient. That makes a later **yes** more defensible.

## Procurement readiness

The public page links buyers to current PPRA standard tender documents/circulars and ODPC guidance rather than pretending VibeSchool can replace the institution's procurement, legal, finance or privacy process.

Public institutions should use the procurement process applicable to them. Commercial terms, security evidence, data roles, implementation responsibilities and acceptance criteria should be inspectable before contract commitment.
