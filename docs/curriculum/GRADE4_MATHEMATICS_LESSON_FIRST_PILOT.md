# Grade 4 Mathematics — Lesson 1 pilot before chapter-scale production

**Scope:** Existing Numbers → Whole Numbers → Place Value and Total Value objective only. This is a scoped implementation/acceptance brief, **not** a new curriculum, publishing authority, content engine or approval process.

## Owner decision

Test **one complete learning objective/lesson first**. Use results to improve the canonical outcome package. Only then repeat the validated process for the remaining verified objectives and assemble/revise a chapter through existing authorized publication and versioning.

The lesson-first **learner entry** is `/learn/grade-4/mathematics/place-value`. Keep the existing published textbook, stable canonical topic ID `0f130af0-8f3c-433a-a0df-453927dece7f`, chapter links, entitlements and reader progress intact. Do **not** delete or downgrade a published chapter in order to run this content experiment.

## Pilot learning package to inspect

- Learner: meaningful prerequisite recall, explanation of place vs total value, five-column chart, four stepped worked examples, guided activity, 15 differentiated exercise items, misconception repair, six-question mastery self-check, recap and home extension.
- Interactive preview: keyboard/screen-reader accessible place-value chart and sensible paper/counter alternatives; this **read-only preview does not mark, score, save or claim mastery**.
- Follow-on practice: existing approved Place Value & Total Value topic-practice destination, which retains its own authentication, marking, feedback and progress contracts.
- Teacher: review the existing canonical Teacher Guide, preparation materials, differentiation, answers/rubric and actual learner/teacher reading routes under their own access rules.
- Curriculum: reconcile the specific first objective against authenticated official source records and stable outcome identifiers before any new certification claims. Treat currently published textbook status and separate source alignment as independent facts.

## Acceptance before scaling

1. **Correctness and pedagogy:** independent math check of all examples, chart states, formative responses, exercises, score/answer secrecy, language and Kenyan contexts.
2. **Real learner journey:** mobile and desktop, signed-out reading where permitted, signed-in learner, chart controls and assistive technology; no false data persistence in preview.
3. **Connected journey:** reader → topic practice → feedback → correction/retry; verify saved results only where the approved practice system actually saves them.
4. **Teacher experience:** content-to-outcome identity, linked Teacher Guide, delivery materials and assessment access in a legitimate teacher session; protect marking keys in public routes.
5. **Publication boundaries:** preview does not unlock drafts, candidate media, uncertified resources or author/publisher privileges; existing published chapter remains reachable.
6. **Evidence:** record exact version/commit, learner screenshots and observed errors, independent review, official curriculum checks, CI, production route check and known gaps. Do not equate a green UI test with student mastery or chapter certification.

## Scale decision

After the pilot is evidence-backed, produce each **next verified learning objective** with the same canonical package (Core → Supplementary Practice → Revision → Teacher Support). Vary the teaching approach to the actual mathematical concept; do not merely clone Lesson 1 prose, examples or item answers. Preserve stable outcome IDs and question provenance, join the lessons under their existing curriculum sub-strand, and release future chapter revisions only through the existing exact-version publishing gates.

**Not included in this UI change:** content mass generation, a new chapter release, new scoring, curriculum approval, unpublished media certification, or production database mutations.
